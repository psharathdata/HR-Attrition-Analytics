#  Project Title: Employee Attrition Analytics & Prediction
Dataset : IBM HR Analytics (Kaggle) 

Tools   : Python · Pandas · Matplotlib · Seaborn · Plotly #  Author  : SHARATH P

Business Problem
Companies struggle to identify employees likely to leave.
This project analyzes employee attrition patterns and predicts high-risk employees using Machine Learning.

Key Insights
Overtime employees show higher attrition risk
Low salary bands have increased turnover
Younger employees are more likely to leave
Job satisfaction strongly affects attrition

| Model               | ROC-AUC |
| ------------------- | ------- |
| Logistic Regression | 0.83    |
| Random Forest       | 0.96    |
| XGBoost             | 0.97    |



Features
Attrition prediction
High-risk employee identification
SHAP explainability
Interactive dashboards
SQL business analysis
